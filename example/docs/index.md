# The example

This app is charter's example: the one app that uses all of charter, and what `go tool charter create` copies. These pages are its own docs, Markdown files in its `docs/` folder, shown by the same pages charter's site uses for its docs.

charter itself is documented at [charter's site](https://charter.gedw99.workers.dev/docs/).

## What is in it

| Where | What |
|---|---|
| [The home page](../) | Notes, live: write one and it shows at once on every open page |
| [The bindings page](../bindings) | A card for everything Cloudflare gives a Worker |
| [The API](/api/openapi.json) | The notes API, from a contract, with tokens, limits, a stream and SDKs |
| These pages | Docs from Markdown |

## Making it yours

Replace these files with your own docs. A page is a Markdown file; its first heading is its title, and its file's name is its address. See [how it is built](01-how-it-is-built.md).
