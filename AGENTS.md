# For agents

Everything about this repo is in [docs/](docs/README.md), the same pages developers read. Nothing is kept here, so there is one source of truth.

Read, in this order:

1. [docs/README.md](docs/README.md): what is what. The repo has two servers, two contracts and two Fern folders, and they are easy to mix up.
2. [docs/rules.md](docs/rules.md): the working rules. They are binding.
3. The page for the part you are changing: [docs/api.md](docs/api.md), [docs/api-go.md](docs/api-go.md), [docs/sdk.md](docs/sdk.md), [docs/testing.md](docs/testing.md), [docs/dev.md](docs/dev.md).
4. [docs/plans/next.md](docs/plans/next.md) for what is planned, and [docs/findings.md](docs/findings.md) for what has been verified.

When you learn or change something, write it in the page in `docs/` it belongs to. Don't add README files elsewhere.
