# For agents

Everything about this repo is in `docs/`, the same pages developers read. Each `@` line below is that page, loaded with this file (Claude reads them; any other agent: read them, in this order). The rules are binding.

@docs/README.md
What is what, and the index of every page. The repo has two servers, four contracts and four Fern folders, and they are easy to mix up.

@docs/charter/README.md
How this repo is kept: what is charter's.

@docs/charter/rules.md
The rules every repo charter keeps shares.

@docs/rules.md
This repo's own rules.

@docs/contributing.md
A change to charter itself: try it on a throwaway repo, then release.

@docs/charter/using.md
Every charter command.

@docs/charter/tasks.md
Every task, in the order you run them: the flow. All of it runs here.

Before you change a page in `docs/`, read [docs/charter/writing.md](docs/charter/writing.md). Write what you learn in the page it belongs to; don't add README files elsewhere.
