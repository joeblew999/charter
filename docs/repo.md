# How this repo is kept

Written by `charter docs` (the same pages in every repo that uses it): don't edit them here, change `cmd/charter/docs/repo.md` and `cmd/charter/docs/repo/` in [charter](https://github.com/joeblew999/charter).

Every repo that uses charter is kept the same way, so a developer or an agent who knows one knows them all. What is the same is on these pages; what is this repo's own is on its other pages.

| Page | What it is |
|---|---|
| [Rules for every repo](repo/rules.md) | The working rules, for developers and agents alike. This repo's own rules, if it has more, are in its `rules.md` |
| [Writing docs](writing.md) | The rules a page in `docs/` is held to |

What charter keeps in a repo, and the tasks for each part: [Any repo](https://joeblew999.github.io/charter/guides/any-repo.html). Every file charter writes says so in its first lines, and `charter files` lists them.
