Theme editor

Pick one of 8 component styles, then shape the semantic theme it renders with: base color, accent, chart color, menu accent, radius, and a body/heading font pair, all previewed live in light and dark. Undo/redo, the address bar, and share codes track every change, and a foreign theme.css imports straight in. The gallery renders the exact component source a project receives from gsxui add under the selected style.
