# charter-start-go

A Go API on Cloudflare Workers, from a Huma contract (`api/contract.go`), built with TinyGo, made with [charter](https://joeblew999.github.io/charter/). `charter check` is every check that needs no Cloudflare account (`mise run charter:check`; in charter's repo, `go tool charter check`), and `charter.toml` says everything charter knows about it.
