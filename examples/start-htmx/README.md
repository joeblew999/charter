# charter-start-htmx

A Go API on Cloudflare Workers with server-rendered pages (htmx 4, gsx), live over its streams, made with [charter](https://joeblew999.github.io/charter/): [Server-rendered pages](https://joeblew999.github.io/charter/self/pages.html). `charter check` is every check that needs no Cloudflare account (`mise run charter:check`; in charter's repo, `go tool charter check`), and `charter.toml` says everything charter knows about it.
