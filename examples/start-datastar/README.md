# charter-start-datastar

A Go API on Cloudflare Workers with server-rendered pages (Datastar, gsx), live over its streams, made with [charter-ts](https://joeblew999.github.io/charter/): [Server-rendered pages](https://joeblew999.github.io/charter/self/pages.html). `npm run check` is every check that needs no Cloudflare account; the commands are the scripts in `package.json`, and `charter.config.ts` says what they need.
