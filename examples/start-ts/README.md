# charter-start-ts

A TypeScript API on Cloudflare Workers, from an oRPC contract (`api/contract.ts`), made with [charter](https://joeblew999.github.io/charter/). `charter check` is every check that needs no Cloudflare account (`mise run charter:check`; in charter's repo, `go tool charter check`), and `charter.toml` says everything charter knows about it.
