# charter-start-ts

A TypeScript API on Cloudflare Workers, from an oRPC contract (`api/contract.ts`), made with [charter-ts](https://joeblew999.github.io/charter/). `npm run check` is every local check, with no Cloudflare account; the steps are the scripts in `package.json`, in the order you run them, and `charter.config.ts` says what they need.
