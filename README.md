# orpc-api

An oRPC API on Cloudflare Workers, contract first, with real-time (SSE + WebSockets) that doesn't lose data. Typed SDKs, a CLI and a docs site are generated from it with Fern. It's the base for our other API projects: copy the patterns, not the notes.

- **One contract** (`api/src/contract.ts`, Zod 4) gives:
  - plain REST, SSE (`notes.watch`) and a WebSocket (`notes.live`), served by oRPC 2.0 on a Worker with D1;
  - an **OpenAPI** and an **AsyncAPI** spec, both generated (nothing hand-written);
  - **SDKs** (Go, TypeScript), a **Rust CLI** and **docs**, generated by Fern from those specs.
- **Real-time that holds up on Cloudflare.** One primitive, `follow()`, gives every client a gap-free feed across deploys, Durable Object restarts, disconnects and long idle periods. The hub hibernates. It's tested live by a client × scenario matrix (`mise run api:soak`).
- **Upstream gaps are tracked.** Every workaround names its Fern or oRPC issue, and `mise run upstream:status` shows which are fixed.

## Quick start

Needs [mise](https://mise.jdx.dev) and Docker (for Fern).

```sh
mise install              # node, jq, gh (mise.toml), Rust (rust-toolchain.toml), Go (go.work)
mise run setup            # npm packages
mise run check            # every local check: typecheck, unit tests, spec drift, SDKs, the SDK inside workerd
mise run dev              # the API on http://localhost:5173 (first time, in another shell: mise run db:migrate:local)
mise tasks                # everything else
```

Deploying needs a Cloudflare login (`api/node_modules/.bin/cf auth login`, or `CLOUDFLARE_API_TOKEN`):

```sh
mise run deploy           # the orpc-api Worker, then its D1 migrations
mise run api:live-test    # SSE + WebSocket + the TypeScript SDK against it
mise run api:soak         # the real-time matrix (redeploys once mid-run)
```

On another Cloudflare account, set `API_URL` (and `HARNESS_URL`, `HARNESS_API_URL`) in `mise.local.toml`, which is gitignored.

## Using it in another project

1. Write the contract with `openapi({...})` and `asyncapi({...})` metadata, as in `api/src/contract.ts`.
2. Copy `api/src/follow.ts`, `api/src/asyncapi.ts` and `api/src/specs.ts` unchanged, and give `follow()` your own source (`subscribe`, `since`, `latest`).
3. Copy `sdk/fern/apis/api/` as your API's Fern folder, plus the `api:*` and `sdk:*` tasks.
4. Follow the client rule from [sdk/README.md](sdk/README.md#real-time-on-cloudflare-the-pattern-to-copy-plansrealtimemd): call again with `after` = the last id.
