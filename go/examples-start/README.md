# charter-start-go

A Go API on Cloudflare Workers, from a Huma contract (`api/contract.go`), built with TinyGo, made with [charter-ts](https://joeblew999.github.io/charter/). `npm run check` is every local check, with no Cloudflare account; the steps are the scripts in `package.json`, and `charter.config.ts` says what they need.
